# 医疗 AI / 医疗器械交付物门禁（17 道门禁 + 双 SHA-256 指纹权属台账）

MedXpert 把AI 交付治理理念工程化落地的可插拔模块：交付前按 17 道门禁校验，并计算双 SHA-256 指纹写入权属台账（provenance ledger），形成可审计的在先发表证据。

## 用法
```bash
git clone https://github.com/stevenzhao07/delivery-guard.git && cd delivery-guard
python scripts/delivery_guard.py --demo
```

## 提供能力
delivery-guard, gate, provenance, dual-sha
