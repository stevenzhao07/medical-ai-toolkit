# MedXpert × LGD 团队文化（TeamAI culture.md）

让每个 AI 编码 Agent 继承我们的工作原则：

- **一切即插件**：仅依赖声明式 `module.json`，零配置、按需装（lazy）、可嵌套。
- **核心通用、领域可插拔**：同一套骨架适配不同行业 / 机构 / 国家（原则零）。
- **人和 AI 都能主动找到并参与**：机器可发现（AGENTS.md / llms.txt / A2A card / TeamAI）+ 低门槛贡献（脚手架 + 全自动测试）。
- **诚实为本**：事实断言须溯源核实；静态目录不谎称实时端点；能力声明与实现一致。
