Every module is a zero-dependency Python CLI that runs on the standard library alone — no cloud service, no scikit-learn, no network access. That is deliberate: compliance artefacts must be auditable offline and reproducible years later.

LGD: the framework underneath

LGD is a governance framework organised around one idea: the core stays industry-neutral, and every domain capability is a plugin loaded on demand.

PropertyIn practice
Everything is a pluginA capability is described by a declarative module.json (id, triggers, provides, entry, dependencies). Adding one does not touch the core.
Load on demandrouter.py reads metadata only, and loads a module's full text only when its triggers match — roughly 20 tokens per module at rest.
NestableA module may itself route to sub-modules. This portal is exactly that: a module made of modules.
Configurable, not forkedIndustry, organisation and locale live in config/. Adopters adapt through configuration and their own private plugins instead of patching the core.

Why this exists

Gap observedWhat this toolkit does
Lifecycle tools exist in isolation, forcing teams to stitch them by hand21 modules share one contract and one routing table, so stages hand off without glue code
Regulatory content assumes US/EU onlyChinese regulation (NMPA orders, GMP revision, recall timelines) sits alongside MDR/FDA/PMDA
Readable by humans, invisible to AI agentsEach module ships AGENTS.md, CLAUDE.md, llms.txt and A2A agent cards, so coding agents discover and call modules without being told
On verifiability. Regulations change, so every factual assertion in these modules states its source; anything that could not be confirmed against a primary text is marked TO_BE_VERIFIED rather than filled with a plausible number. If you find a value that is wrong or out of date, that is a reportable bug, not a nitpick.

How to participate

1 · Report an error

Regulatory values, standard numbers, clause references and dates are all fair game. Open an issue with the source that contradicts us — here, correction is the highest-value contribution.

2 · Try it

Run a module on your own device or dataset and tell us where it stopped being useful.

3 · Contribute

Modules and fixes both welcome. Branch convention, AI-attribution trailer and reading order are in AI_PARTICIPATION.md.

4 · Own a module

Want to maintain one of the 21 repositories long-term? Say which one and what you would change. Handing a module to an outside maintainer is an outcome we want.

Other industries are explicitly welcome. LGD is not a medical framework that happens to be medical: the core is domain-neutral and the medical matrix is the worked example. Keep router.py and harness.py, add your own domains/ modules, and touch nothing medical. A working example already exists — examples/domains/legal-compliance, which turns contract clauses into an obligation ledger on the identical contract, with no medical code in it. Proposals in that direction are as welcome as medical contributions. Open an issue →

LGD：底下的那套框架

LGD 是一套以「内核与行业无关、领域能力皆插件、按需加载」为组织原则的治理框架。

性质具体含义
一切即插件一个能力由声明式 module.json 描述（id、触发词、提供能力、入口、依赖）；新增模块不触碰内核。
按需加载router.py 静止时只读元数据，命中触发词才载入模块全文 —— 每个模块常驻开销约 20 token。
可嵌套模块本身可以再作为入口去路由子模块。本门户正是如此：由模块组成的模块。
配置化，而非改码行业、机构、语区都放在 config/。采用方通过配置与自有私有插件适配，而不是改内核源码。
为什么长成这样：同一套骨架，既能编排一次欧盟 MDR 临床评价，也能编排一次财务内控复核或法律合规流程 —— 可复用的是顺序、门禁与审计轨迹，不是领域内容本身。

为什么做这件事

观察到的缺口本工具的做法
生命周期工具彼此孤立，团队得手工拼接21 个模块共用一份契约与一张路由表，阶段之间无需胶水代码
法规内容默认只讲美欧中国的法规（NMPA 令、GMP 修订、召回时限）与 MDR/FDA/PMDA 并列覆盖
人读得懂、AI 代理看不见每个模块都带 AGENTS.md、CLAUDE.md、llms.txt 与 A2A 代理卡，编码代理无需被告知即可发现并调用
关于可核实性。 法规与标准一直在变，因此这些模块里的每条事实性断言都标出来源；凡是无法对照一手文本确认的，标注 TO_BE_VERIFIED，而不是填一个看起来合理的数字。若你发现某个值有错或过期，那是一个可报的缺陷，不是吹毛求疵。

如何参与

1 · 挑错

法规数值、标准号、条款引用、日期，全都欢迎质疑。请提 Issue 并附上与你所指相矛盾的来源 —— 在这里，纠错是价值最高的贡献。

2 · 试用

用你自己的器械或数据跑一个模块，告诉我们它在哪里开始不好用。

3 · 贡献

模块与修复都欢迎。分支命名、AI 署名 trailer、推荐阅读顺序见 AI_PARTICIPATION.md。

4 · 认领模块

愿意长期维护 21 仓中的某一个？说明你想接手哪个、打算改什么。把模块交给外部维护者，是我们想要的结果。

其他行业同样欢迎，且是明确欢迎。 LGD 不是"碰巧偏医疗"的医疗框架：内核与行业无关，医疗矩阵只是那个已经做出来的样例。保留 router.py 与 harness.py，直接加自己的 domains/ 模块，完全不碰医疗部分。已经有一个可运行的例子 —— examples/domains/legal-compliance：把合同条款转成义务台账，用的是完全相同的契约，其中不含任何医疗代码。这个方向的提案与医疗贡献一视同仁。提 Issue →
